# Herdthink · 平行视角｜首版需求

## 用户为什么打开它

一个人看到“AI 编程提高了效率”，可能想到早点下班，也可能想到评审负担变重。准备读博的人看到相同的经历，也会因经济压力和职业目标得出不同判断。Herdthink 帮用户把差异追到具体材料，找出下一件值得核实的事。

## 一次完整体验

1. 选一个议题。首版提供「AI 编程」和「读博还是工作」两个策展示例，分别验证公共讨论和个人决策场景。
2. 在可旋转的空间图中点一个视角，再选择它关心的问题。旁边显示该视角怎样阅读一条知乎材料、还缺哪些信息，以及可打开的原文。手机和键盘用户也能用普通按钮完成选择。
3. 打开「同源对照」，保持材料不变，比较不同视角的解读。标清材料摘要和产品解读，视角名称只代表观察角度；作者身份、推荐算法和各群体的实际曝光率都需要独立证据。
4. 把有用的关注点加入「观察档案」，可为其写一句自己的约束。回到页面后，个人视角图按议题显示各角度的收藏数，点节点可重看材料、编辑约束或移除记录。首版将档案留在当前浏览器。

## 前端与数据

图上呈现议题、视角及所选关注点之间的关系；正文与出处放在固定阅读区。首版用检索结果快照和人工整理的解读演示。后续先接已有知乎搜索，按材料 ID 生成有出处的多视角解读，再让用户选择是否用自己的约束调整下一轮检索。前端空间坐标独立于后端存储，现有问答入口继续可用。

## 怎么判断值得继续

现场给用户一个议题，请他找出「同一材料的两种解读」，打开出处，并保存一个影响自己判断的问题。观察他能否在两分钟内独立完成，再请他指出哪条材料改变了自己的判断。若大家只记得图会转，就优先改证据和对照流程。
